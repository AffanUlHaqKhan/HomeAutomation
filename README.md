# HomeAutomation

Start of the project for creating a home automation system

its divided into following steps
->Creating UI using QT/QML
->Baking it using yocto into embedded linux
->Making it work on raspberry pi
-> sensor integration to display data in UI


Will be starting with creatinig a very simple basic and rudementary UI and then working on evolving it.
Once the UI is good enough, will move to baking it into linux distro using yocto for raspberry pi and then sensor integration

If there is time or need, will try to work on OTA as well.
